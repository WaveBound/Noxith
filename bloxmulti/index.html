FAQ

Common questions.

How does BloxMulti compare to Roblox RAM?

BloxMulti is a modern Roblox Account Manager and launcher for Windows. Instead of plain-text storage and manual mutex handling, it gives you a clean interface, DPAPI token encryption, automatic mutex unlocks and per-account FPS limits.

How do I play multiple Roblox accounts on one PC?

Roblox uses a singleton mutex to block extra clients. BloxMulti releases that handle before each new window launches, so independent accounts run side by side.

Can I launch specific Place IDs and servers?

Yes. Launch any Place ID, job ID or private server link with the selected account, and save favorites for later.

Is it safe? Can I get banned?

BloxMulti doesn't inject code into Roblox or modify game memory. It works at the Windows level by managing process handles and config files externally.

What happens if my internet disconnects?

With Premium Smart Recovery enabled, BloxMulti keeps the disconnected game open until Roblox is reachable again. It then closes the game normally, relaunches the account and restores its window position. Optional Discord alerts keep disconnect and reconnect notifications in order.

Where are my logins stored?

Only on your PC. Session tokens are encrypted with the Windows Data Protection API and tied to your user profile.
