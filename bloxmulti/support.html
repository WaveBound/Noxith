Need assistance setting up BloxMulti or troubleshooting multi-instance launching? Find answers to frequently asked questions below or reach out to our community.

Frequently Asked Questions (FAQ)

What is BloxMulti?

BloxMulti is a lightweight, portable Windows utility that lets you launch and manage multiple Roblox client instances concurrently on a single PC. It isolates each account's session with its own token vault and unlocks singleton Mutex handles automatically.

Do I need to install anything for the UI to work?

BloxMulti uses Microsoft Edge WebView2 to render its user interface. Most Windows 10 and 11 machines include this runtime by default. If the app displays a blank window or fails to open, install the official WebView2 Evergreen Runtime from Microsoft.

Can I get banned for using BloxMulti?

BloxMulti does not inject code into the Roblox game engine or alter in-game memory. It manages native Windows Mutex objects and handles session launching. However, always ensure your use complies with Roblox's Terms of Use.

Troubleshooting Common Issues

Windows SmartScreen blocked the app

  • Because BloxMulti is a portable executable without an expensive commercial code-signing certificate, Windows SmartScreen may display an unrecognized app notice. Click More info and select Run anyway.
  • If the file was downloaded from a browser, right-click BloxMulti.exe, select Properties, check the Unblock box at the bottom, and click Apply.

Accounts or tabs are not saving

Ensure the executable is placed in a folder with full read and write permissions (such as Desktop, Documents, or a custom folder like C:\BloxMulti). Avoid running directly from a temporary zip folder or write-protected system directories.
